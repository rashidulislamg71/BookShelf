

# 📚 BookShelf – Online Book Borrowing Platform

BookShelf is a modern and user-friendly web application where users can browse, explore, and borrow books easily from anywhere.

---

## 🚀 Live Features

* 🔐 Authentication system (Login / Logout)
* 📖 Browse all books
* 📚 Book details (Private Route)
* ⭐ Ratings and Reviews UI
* 🎯 Borrow Book system with toast notification
* 👤 User Profile (Private Route)
* 🎨 Modern UI with TailwindCSS & DaisyUI
* ✨ Smooth animations using React Spring

---

## 🔒 Private Routes

* **Book Details Page**
* **My Profile Page**

👉 Only logged-in users can access these pages
👉 If not logged in → automatically redirected to Login page

---

## 👤 User Profile

Displays logged-in user information:

* Name
* Email
* Profile Image

---

## 🛠️ Tech Stack

* Next.js (App Router)
*  Tailwind CSS + DaisyUI
* Better Auth (Authentication)
* MongoDB (Database)
* React Spring (Animations)
* React Hot Toast (Notifications)
